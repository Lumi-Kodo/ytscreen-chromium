# YouTube Screen Chromium

Chromium (CEF) for Minecraft 1.21.1 (NeoForge), used by the YouTube Screen mod.
A fork of [MCEF](https://github.com/CinemaMod/mcef) by montoyo and the CinemaMod Group, built on
[CCBlueX's fork of java-cef](https://github.com/CCBlueX/java-cef) (Chromium 152).

Work in progress.
